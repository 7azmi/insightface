### 1. Face Mesh Topology Demo (NEW!)

**Local web demo** for detecting and visualizing face topology/mesh from images.

- **Location**: [face_mesh_demo/](face_mesh_demo/)
- **Features**: 
  - Face detection and landmark visualization
  - Single and multiple image processing
  - Web interface (Gradio) + CLI tool
  - Detailed installation guide for Linux Mint
- **Quick Start**: `cd face_mesh_demo && ./start_demo.sh`
- **Documentation**: See [README.md](face_mesh_demo/README.md)
